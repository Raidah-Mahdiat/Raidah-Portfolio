# Portfolio — Raidah Mahdiat

This is Raidah Mahdiat's personal portfolio website. It is a responsive static site built with HTML and CSS, with a small JavaScript snippet for the footer year.

The page currently includes:

- A hero section with links to projects, contact details, and the resume
- An about section with focus areas, availability, and contact information
- Three project cards with screenshots for the Amazon Clone, Etsy Clone, and Helping Hand projects
- Skills, work experience, education, and contact sections
- Responsive layouts for desktop, tablet, and mobile screens

## Project structure

```text
.
├── index.html
├── style.css
├── Raidah Mahdiat.pdf
├── amazon-clone.png
├── etsy-clone.png
└── helping-hand.png
```

Then open [http://localhost:8000](http://localhost:8000) in a browser. The **View Resume** link opens `Raidah Mahdiat.pdf` in a new tab.
